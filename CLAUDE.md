# Military Move Revenue

## Purpose

Build a source-backed, read-only post-audit system for domestic Defense Personal
Property Program (DP3) shipments. Version one reconstructs what a Transportation
Service Provider (TSP) should have billed the government, checks supporting
evidence, compares expected, invoiced, and paid amounts, and explains every
result using effective-dated authoritative sources.

## Gotchas

- A pickup date selects a rule package; today's rule is not automatically the
  applicable rule.
- Government billing and private agent compensation are different financial
  relationships. Version one covers only TSP-to-government billing.
- A public article or vendor explanation is contextual material, not governing
  authority.
- Forms, tariffs, rate tables, EDI specifications, and historical packets answer
  different schema questions and must retain separate provenance.
- Real shipment files must not enter this project without written authorization
  and approved sanitization.

## Rules for agents

- Read `AGENTS.md`; it is the canonical operating policy.
- Do not implement a billing rule without a source citation and effective dates.
- Never report a financial result produced solely by a language model.
- Record contradictions rather than silently choosing or averaging values.
- Do not hand-edit generated artifacts once generators exist.
- Never place secrets or unsanitized shipment data in the repository.
